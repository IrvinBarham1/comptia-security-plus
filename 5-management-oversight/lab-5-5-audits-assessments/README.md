# Lab 5.5 — Security Program Management and Oversight

## 🎯 Objective
**“Explain types and purposes of audits and assessments.”**

This lab explores how organizations **validate security controls, verify compliance, and test resilience** through structured audits and penetration assessments.  
It covers both **internal and external review processes**, as well as various **testing environments and reconnaissance methods** used to evaluate security effectiveness.

---

## 📖 Background

Audits and assessments are essential for maintaining accountability and continuous improvement within a security program.  
They provide visibility into how well security controls operate, identify deficiencies, and ensure alignment with organizational or regulatory standards.  
Penetration testing complements audits by actively probing systems and infrastructure to uncover real-world vulnerabilities before adversaries can exploit them.

### Core Focus Areas

| Category | Purpose | Example Topics |
|:--|:--|:--|
| **Attestation** | Provide formal verification of control effectiveness | Certification reports, Compliance attestations |
| **Internal Audits** | Evaluate internal adherence to policies and controls | Compliance Audits, Audit Committees, Self-Assessments |
| **External Audits** | Provide independent validation for external oversight | Regulatory Reviews, Examinations, Third-Party Assessments |
| **Penetration Testing** | Actively test security through simulated attacks | Physical, Offensive, Defensive, Integrated, Known/Unknown Environments |
| **Reconnaissance** | Gather intelligence prior to testing | Passive (OSINT, DNS, WHOIS), Active (Scanning, Enumeration) |
